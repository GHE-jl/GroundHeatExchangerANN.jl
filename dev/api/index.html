Model tags

GroundHeatExchangerANN.AbstractANN — Type
AbstractANN

Model tag selecting which trained short-term ANN ann_nodes, ann and outlet_transfer_function (GroundHeatExchanger.jl) evaluate.

source
GroundHeatExchangerANN.PublishedANN — Type
PublishedANN()

Short-term ANN of Pasquier, Zarrella & Labib (2018): 8 physical inputs (pipe properties fixed), 85 time nodes, 7-day validity horizon. See ann(::PublishedANN, ...) for the validity ranges. Implemented in ann_published.jl.

source
GroundHeatExchangerANN.DeepANN — Type
DeepANN()

Short-term ANN of Pasquier & Marcotte (2020): pipe properties (kp, Cf, ri, ro) are free parameters with their own (wider) validity ranges, 95 time nodes, 21-day validity horizon. This is the default model tag for outlet_transfer_function (GroundHeatExchanger.jl). See ann_nodes(::DeepANN, ...) for the validity ranges. Only the borehole-outlet response is exposed (the underlying network can in principle report the temperature at any probe location along the U-tube). Implemented in ann_deep.jl.

Transfer functions

GroundHeatExchangerANN.ann — Function
ann(::PublishedANN, t, rb, ri, ro, H, s, V̇, ks, Cs, kg, Cg, kp, Cp, Cf; clamp=true)

Short-term transfer function of the borehole-outlet fluid temperature (T_out, i.e. the entering water temperature on the heat-pump source side), constructed with the artificial neural network of Pasquier, Zarrella & Labib (2018). The network emulates the 2.5D thermal resistance and capacity model and directly yields a dimensionless transfer function for a unit temperature step (ΔT = 1 °C) between the borehole inlet and outlet, so it embeds the borehole geometry, thermal capacity and vertical fluid advection. The mean absolute error with respect to the reference model is about 2e-4, with a maximum absolute error near 8e-3. The function is only valid over the 7-day short-term horizon and within the ANN training ranges (see below); use outlet_transfer_function of GroundHeatExchanger.jl to join it to a long-term ground model for the full minutes-to-decades response.

Arguments

- `t`: Time value or vector [s] (maximum of 7 days)
- `rb`: Borehole radius [m]
- `ri`: Inner pipe radius [m]
- `ro`: Outer pipe radius [m]
- `H`: Borehole length [m]
- `s`: Shank spacing (distance between the two legs of the U-tube) [m]
- `V̇`: Fluid flow rate [m³/s]
- `ks`: Ground thermal conductivity [W/mK]
- `Cs`: Ground volumetric heat capacity [J/Km³]
- `kg`: Grout thermal conductivity [W/mK]
- `Cg`: Grout volumetric heat capacity [J/Km³]
- `kp`: Pipe thermal conductivity [W/mK]
- `Cp`: Pipe volumetric heat capacity [J/Km³]
- `Cf`: Fluid volumetric heat capacity [J/Km³]
- `clamp`: out-of-range handling, `true` (default) clamps inputs to the training bounds
    and emits a `@warn`; `false` emits an `@error` and throws an `ArgumentError`.

Output

- `t`: Evaluation time(s) [s] (the last value clamped to the horizon when `clamp` is `true`)
- `g`: Dimensionless short-term outlet transfer function at `t` [-]

Validity ranges (ANN training bounds)

- t: 15 s – 7 days (horizon applied to the last value)
- rb: (2ro+2mm)–0.1 m
- ri: 0.017 m
- ro: 0.022 m
- H: 110–200 m
- s: 2(0.02(rb-2ro)+ro) – 2(0.98(rb-2ro)+ro) m (twice the half-shank spacing)
- V̇: 3.33e-4–5.0e-4 m³/s
- ks: 0.5–4 W/mK
- Cs: 1.7–2.6 MJ/m³K
- kg: 0.5–3 W/mK
- Cg: 1.7–2.6 MJ/m³K
- kp: 0.4 W/mK
- Cp: 1.9 MJ/m³K
- Cf: 4.2 MJ/m³K

Reference

- Pasquier, P., Zarrella, A., & Labib, R. (2018). Application of artificial neural networks
    to near-instant construction of short-term g-functions. Applied Thermal Engineering,
    143, 910–921. https://doi.org/10.1016/j.applthermaleng.2018.07.137
source
ann(::DeepANN, t, rb, ri, ro, H, s, V̇, ks, Cs, kg, Cg, kp, Cp, Cf; clamp=true)

Short-term transfer function of the borehole-outlet fluid temperature from the deep ANN (Pasquier & Marcotte, 2020), PCHIP-interpolated onto arbitrary t from the 95 native nodes of ann_nodes. Same argument order and meaning as ann(::PublishedANN, ...); see ann_nodes(::DeepANN, ...) for the validity ranges and the outlet-only caveat.

source
GroundHeatExchangerANN.ann_nodes — Function
ann_nodes(::PublishedANN, ks, Cs, kg, Cg, kp, Cp, Cf, ri, ro, rb, H, V̇, s; clamp=true)

Evaluate the ANN on its fixed native time nodes, returning (ts, g) where ts are the node times [s] — geometric, with the last node marking the short-term validity horizon — and g is the raw short-term transfer function on those nodes — no interpolation and no time validation, unlike ann. This is the low-level building block: ann adds PCHIP interpolation onto arbitrary t, and the short-/long-term join outlet_transfer_function of GroundHeatExchanger.jl consumes the raw nodes directly (it splices at ts[end] and does its own interpolation). Inverts the training transformation y = ln(t̃ / (g + 1)) (85 nodes). See ann_nodes(::DeepANN, ...) in ann_deep.jl for the wider-range 95-node/21-day model.

source
ann_nodes(::DeepANN, ks, Cs, kg, Cg, kp, Cp, Cf, ri, ro, rb, H, V̇, s; clamp=true)

Evaluate the deep ANN (Pasquier & Marcotte, 2020 / SULoop_TRCMz_ANN.m) on its 95 fixed native time nodes, returning (ts, g) — see ann_nodes(::PublishedANN, ...) for the general contract (no interpolation, no time validation). Unlike the published net, this network can in principle report the temperature at an arbitrary probe location along the U-tube (parametrised by a flow-path distance L from the inlet, 0 ≤ L ≤ 2H); only the borehole outlet is exposed here (L = 2H, i.e. Data.T_Probe_Location = [0; 5] in the MATLAB source — depth z = 0 on the ascending/return leg, id 5, so L = 2H - z = 2H), matching the published net's outlet-only signature. Inverts the training transformation g = ts / exp((exp(y) - 4.5) + ym) - 1 (y the raw 95-dim linear output of the network, ym a per-node constant fit during training — not the same formula as the published net's y = ln(ts / (g + 1))).

Validity ranges (ANN training bounds)

- t: 15 s – 21 days (horizon applied to the last value)
- ks: 0.25–8 W/mK
- Cs: 1.4–3 MJ/m³K
- kg: 0.25–5 W/mK
- Cg: 1.4–3 MJ/m³K
- kp: 0.3–1.0 W/mK
- Cp: 1.9 MJ/m³K (fixed)
- Cf: 3.8–4.3 MJ/m³K
- ri: 0.012–0.027 m
- ro: 0.015–0.036 m
- rb: (2ro+2mm)–0.1 m
- H: 50–250 m
- V̇: 15–35 L/min
- s: 2(0.01(rb-2ro)+ro) – 2(0.99(rb-2ro)+ro) m (twice the half-shank spacing)

Reference

- Pasquier, P., & Marcotte, D. (2020). Robust identification of volumetric heat capacity and
    analysis of thermal response tests by Bayesian inference with correlated residuals.
    Applied Energy, 261, 114394. https://doi.org/10.1016/j.apenergy.2019.114394
